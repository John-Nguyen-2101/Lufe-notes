# LufeNote 
A modern note taking web application built with Next.js.

---
## About

LufeNote is a personal note management application designed to help users create, organize and manage notes efficiently.

This project is mainly created for learning modern web development using Next.js App Router.

## 🚀 Features

- Create notes
- Edit notes
- Delete notes
- Search notes
- Responsive design
- Authentication (Coming Soon)

---

## 🛠 Tech Stack

- Next.js 15
- React
- TypeScript
- Tailwind CSS
- Supabase
- Prisma (Future)
